# 接话 1.0

独立 AstrBot 插件，不依赖「识君」或其他文风插件。本插件负责已唤醒的 QQ / OneBot 文本消息等待、合并、收尾与上下文衔接。

## 配置入口

插件列表 → **接话** → **齿轮（配置）**。每项都有说明与注意事项，直接用布尔开关切换。保存配置后 AstrBot 按其原有插件配置机制生效。

默认开启：等待连续发言、明确问题立即处理、超时回复、不完整时简短追问、尊重明确等待、收尾不回复、上下文衔接。

默认等待 8 秒，每条补充重新计时，一组最长等待 30 秒。识别为明确问题则不主动等待。

**更新生成中的回复默认关闭**，可在齿轮开启。开启后本插件纳管的纯文本采用非流式输出；未发出且未执行工具的旧回答可被抑制，下一请求结合此前未回答的发言生成。已经开始发送、已经执行工具或未纳管的请求不重跑。工具执行期间的补充使用 AstrBot 原有 follow-up 能力。

## 延迟与费用

- 不使用独立判断模型，无额外 API Key、服务或模型依赖。
- 等待与合并只用本地规则，可把多次普通回复合为一次；8 秒是开始生成前的等待，模型本身还需时间。
- 上下文衔接在原请求中加入短规则，会增加少量输入 token。
- 更新生成中的回复可能丢弃一轮已计费输出，再生成一轮；不强杀网络请求，不承诺退还已消耗 token。默认关闭用于控制费用。
- 复杂语义仍由现有回复模型判断。关键词规则不能可靠判断所有句子是否说完，也无法感知 QQ 对方正在打字。

## 行为边界

- 只合并同一会话、同一真实发送者的纯文本；机器人自身的 @ 保留。附件、语音、引用、指令直接走原流程。
- 使用现有会话锁，不替换 AstrBot 调度器。其他插件自行发送的主动消息不受此插件控制。
- 明确“稍等”“我还没说完”“等我写完再说”等先静默。后续消息带上暂存前文，模型判断条件是否满足。
- 收尾只匹配保守的整句表达，不按任意关键词吞消息。
- 没有后文时默认等 8 秒再生成；关闭超时回复则暂存。明确缺少后文的消息可允许一次简短追问。
- 静默暂存不写磁盘，保留 10 分钟；过期、插件重载或服务重启会失去这些尚未进入模型历史的消息。
- 普通合并后由 AstrBot 保存合并发言的历史；被抑制的旧回复不应进入回复历史。
- 本插件不调用模型、不发送测试 QQ 消息、不修改其他插件配置，不保证解决其他插件独立主动回复或历史注入造成的重复。

## 验证

在部署版本的真实 AstrBot Python 环境中执行自动测试，覆盖：本地策略开关、同人合并、发送者与会话隔离、明确等待后续接入、超时开关、缺失信息追问规则、指令与媒体透传、旧回答抑制和原文接续、工具和已发送保护、默认不开启额外重生成、卸载时等待事件释放。

真实聊天效果由用户试聊验收。齿轮中可关闭整个插件回到原路径。

## 安装

在 AstrBot 插件管理中选择通过仓库链接安装，填写：

https://github.com/KujouVan/astrbot_plugin_jiehua

要求 AstrBot >= 4.29.1，适用于 aiocqhttp / OneBot 平台。安装后进入插件齿轮配置调整开关。
